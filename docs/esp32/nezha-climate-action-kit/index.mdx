# 城市气候守护套装

城市气候守护套装是一款面向 K12 气候教育、环境监测与编程实践的教育产品套装。
*感知城市气候，识别行动场景，用编程驱动改变。*

学生可以通过环境传感器采集气候数据，并使用 Nezha For ESP32 Board 编写程序，控制风扇、水闸和其他执行装置，从而理解气候感知、编程控制与气候行动之间的关系。

## **产品介绍**

Climate Action Kit｜城市气候守护套装是一款面向 K12 编程教育、STEM / STEAM 课程和项目式学习设计的城市气候行动主题套装。它将真实环境数据采集、RFID 场景识别、积木模型搭建、自动控制和 IoT 数据展示整合在同一套学习系统中。

套装以高温、城市热岛、强光暴晒、暴雨积水、气象变化和低碳出行为学习线索。学生可以使用哪吒 ESP32 多功能主控盒读取板载及外接传感器数据，通过 RFID 传感器识别自定义卡片，再结合风扇模块、电机、屏幕、扬声器和专属 IoT 平台，搭建能够“感知—判断—行动—记录”的城市气候装置。

套装包含 11 个循序渐进的普通案例和 1 个主题综合案例。其中，“智慧低碳候车站”作为代表性搭建案例，将温湿度检测、光照检测、自动遮阳、风扇降温与 RFID 绿色出行打卡整合在一座标志性的城市公共设施中；学生完成基础案例后，还可以挑战功能更完整的“城市气候安全站”。

学生将经历从“发现问题”到“采集数据”、从“搭建模型”到“编写程序”、从“自动响应”到“IoT 记录与成果展示”的完整项目式学习过程，并以城市小工程师的身份提出可验证的气候行动方案。

## **从真实问题出发**

高温、强光、暴雨积水和城市热岛等现象与日常生活紧密相关。学生可以通过温湿度、水位、光照、声音和气压等数据观察身边的环境变化，也可以使用 RFID 自定义卡片开展绿色出行等互动任务。

从街道、公交站和屋顶，到教室、社区花园和低洼路面，每个场景都可以成为探究气候问题的学习空间。学生将在观察、搭建、编程、测试和展示的过程中，把抽象的环境概念转化为可操作、可验证的项目成果。

## **产品特性**

**1\. 从板载传感器入门**

哪吒 ESP32 多功能主控盒内置光敏传感器、双降噪麦克风、陀螺仪、扬声器、屏幕和 RGB 灯。学生无需连接外部模块，也可以完成光照检测、噪音观察、姿态检测和数据反馈等入门实验。

**2\. 从本地数据显示到 IoT 数据看板**

学生可以先在主控盒屏幕上查看数据，再将板载传感器或外接传感器采集到的数据上传到专属 IoT 平台。通过数据看板，学生可以观察一段时间内的光照、噪音、温度、水位或气压变化，也可以记录 RFID 绿色出行打卡次数。

**3\. 传感器与执行器联动**

套装强调“数据触发动作”。学生不仅能读取传感器数据，还能让风扇模块和电机驱动结构产生真实动作，例如启动风扇、展开遮阳棚、升降闸门或驱动巡检车等。

|环境变化|数据来源|执行反馈|
|---|---|---|
|温度过高|温湿度传感器|风扇模块启动，模拟降温|
|光照过强|板载光敏传感器|电机带动遮阳棚展开|
|水位升高|水位传感器|电机升起警戒闸门或启动排水泵模型|
|识别到绿色出行卡|RFID 传感器与自定义卡片|电机开启通行闸门，屏幕显示并累计低碳出行次数|
|噪音过高|板载双降噪麦克风|屏幕提示，扬声器提醒|
|气象塔倾斜|板载陀螺仪|屏幕提示结构异常，扬声器报警|
|需要移动采集|多传感器组合|电机驱动小车到不同区域采集数据|

**4\. 积木模型搭建**

套装支持使用积木结构件搭建不同的城市气候装置，让抽象数据变成看得见、摸得着、能互动的模型。

套装案例包括：

- 城市光照观察器；

- 城市噪音观察器；

- 倾斜安全气象塔；

- IoT 城市微环境看板；

- 自动降温风扇；

- 智能遮阳站；

- 低碳出行打卡站；

- 智慧低碳候车站；

- 积水警戒闸门；

- 城市天气趋势记录器；

- 城市热岛探测车；

- 城市气候安全站。

**5\. 标志性综合项目**

“智慧低碳候车站”将站牌、活动遮阳棚、降温风扇、数据显示和 RFID 刷卡区整合在一座城市候车站中。学生可以通过这个完整作品综合运用传感器读取、条件判断、电机控制、变量计数和结构设计知识。

候车站在温度过高时启动风扇，在光照过强时展开遮阳棚；识别到绿色出行卡后，屏幕显示提示并累计低碳出行次数。案例将“改善城市候车环境”和“鼓励绿色出行”结合起来，使气候行动主题更加具体、可见和可互动。

**6\. 课程任务驱动**

每个案例均围绕真实问题展开，引导学生完成完整的学习闭环：

1. 观察一个城市气候或环境问题；

4. 编写判断和响应程序；

5. 上传或显示实时数据；

6. 记录并比较环境变化；

7. 测试装置效果；

8. 讨论如何优化方案；

9. 展示最终作品。



## **模块介绍**

**哪吒 ESP32 多功能主控盒**

哪吒 ESP32 多功能主控盒是本套装的核心控制器。它负责运行程序、读取传感器数据、控制风扇模块、电机和屏幕反馈，并支持将数据上传到专属 IoT 平台。

主控盒内置屏幕、光敏传感器、双降噪麦克风、陀螺仪、扬声器、可编程按键和 RGB 灯，适合从基础传感器实验逐步过渡到综合项目。

**风扇模块**

风扇模块可由 GPIO 口直接驱动，用于模拟城市降温、通风和空气流动。学生可以根据温度或不同实验条件控制风扇启动和停止。

**RFID 传感器与自定义卡片**

RFID 传感器可读取自定义卡片的识别信息，用于模拟绿色出行打卡、身份认证或气候行动任务触发。学生可以根据卡片识别结果编写判断程序，让闸门、电机、屏幕、RGB 灯或扬声器产生对应反馈。

**电机**

电机用于驱动遮阳棚、闸门、排水模型和移动探测车，让学生的作品从“显示数据”升级为“自动行动”。

## **代表性案例**

**智慧低碳候车站｜Smart Low-Carbon Bus Stop**

智慧低碳候车站将城市气候改善与绿色出行结合起来。学生需要搭建候车站底座、站牌、活动遮阳棚、降温风扇、数据显示区和 RFID 刷卡区，让模型能够根据环境变化自动采取行动。

|学习问题|如何让低碳出行在炎热、强光的城市环境中更加舒适？|
|---|---|
|环境感知|温湿度传感器检测温度，板载光敏传感器检测光照|
|自动响应|温度过高时启动风扇；光照过强时展开遮阳棚|
|互动功能|识别 RFID 绿色出行卡，显示提示并累计打卡次数|
|主要知识点|城市热岛、绿色出行、传感器与执行器、条件判断、变量计数、阈值与回差、机械传动|
|建议难度|中高阶|
|建议时长|1～2 课时|
|拓展方向|将温度、光照和绿色出行次数上传到 IoT 平台；设计低碳出行积分规则|

该案例具有鲜明的城市公共设施特征，功能丰富、互动直观，适合用于课堂教学、公开课、社团活动和科技节展示。



## **主题案例**

**城市气候安全站**

城市气候安全站是本套装的主题综合案例。它将温湿度、水位、光照、噪音、气压、RFID 绿色出行卡识别和 IoT 数据展示整合在同一个城市模型中，通过风扇模块、遮阳棚、积水警戒闸门、绿色通行闸门、屏幕和扬声器完成自动响应。

学生可以在这个综合项目中连接不同环境数据与执行反馈，探索更完整的城市气候监测和自动响应方案。

- 掌握传感器读取、条件判断、变量、循环、电机与风扇控制等编程知识；

- 运用工程设计方法完成结构搭建、功能测试和方案优化；
- 使用 IoT 数据看板观察趋势，并结合数据解释项目效果；
- 通过模型演示、程序和数据展示自己的城市气候行动方案。
