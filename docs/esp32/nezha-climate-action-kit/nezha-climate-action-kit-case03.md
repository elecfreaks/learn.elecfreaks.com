# 案例三：倾斜安全气象塔

## 案例简介

小型气象塔受到碰撞或底座不稳时，如何及时发现倾斜？本案例搭建气象塔模型，通过 **Nezha ESP32** 的板载姿态传感器检测姿态变化。当选定方向的倾斜超过阈值时，屏幕显示警告，并可配合提示音。学生在调整底座和报警条件的过程中，认识姿态检测与模型稳定性。

学生将通过搭建、编程和测试，把观测结果与模型的显示或动作联系起来，学习用数据解释现象。

通过本案例，学生可以结合课堂观察与工程实践，思考如何利用技术改善校园和城市环境。

## 教学目标

完成本案例后，学生能够：

1. 观察姿态读数与主控安装方向之间的关系。
2. 设置基准姿态，使用角度或偏差进行条件判断。
3. 通过测试评价结构稳定性和报警灵敏度。
4. 根据测试结果调整参数，经历“设计—编程—测试—改进”的工程实践过程。

## 课程引入

展示一个底座较窄的积木塔，请学生预测哪种方向更容易倾倒。讨论：我们能否在塔倒下前，通过姿态变化发现异常？本案例只模拟倾斜提示，不作为真实建筑安全监测设备。

本节课中，我们将扮演“城市环境设计师”，搭建倾斜安全气象塔，用实际观测检验自己的设计。

## 学习探究

在开始搭建前，可以分组讨论以下问题：

1. 主控安装方向改变后，同样的倾斜会对应哪个轴？
2. 为什么应该先记录模型直立时的读数？
3. 轻微晃动与持续倾斜需要相同的报警方式吗？
4. 你会怎样记录测试条件，说明结果是否符合预期？
5. 如果把模型应用到真实环境，还需要考虑哪些因素？

## 程序设计

程序分为“启动初始化”和“循环运行”两个部分。

### 1. 启动初始化

<!-- 图片占位符：启动初始化程序截图 -->
<!-- 建议文件名：./images/tilt-safety-weather-tower-program-init.png -->

程序启动后将执行以下操作：

1. 在模型直立且静止时记录所选轴的角度或基准值。
2. 初始化屏幕与数据变量，避免沿用上一次运行的状态。
3. 在屏幕预定位置显示数据标签与初始运行状态。

主控盒屏幕的显示布局如下：

| 屏幕行 | 显示内容 |
| ---: | --- |
| 第 1 行 | 倾斜偏差 |
| 第 2 行 | 相对直立基准的偏差 |
| 第 3 行 | 运行状态 |
| 第 4 行 | 稳定 / 倾斜提醒 |

### 2. 循环检测与控制

<!-- 图片占位符：循环检测与控制程序截图 -->
<!-- 建议文件名：./images/tilt-safety-weather-tower-program-main.png -->

在 `forever` 循环中，系统会持续执行以下任务。

#### 建立基准

- 在模型直立且静止时记录所选轴的角度或基准值。

#### 计算偏差

- 读取当前值，计算其与基准的差的绝对值。

#### 报警判断

- 偏差超过阈值时提醒，回到安全范围后解除。

### 3. 关键参数

| 参数 | 示例值 | 含义 | 调整建议 |
| --- | ---: | --- | --- |
| 检测轴 | 待实机确认 | 先逐方向倾斜验证 | 由主控安装方向确定 |
| 倾斜阈值 | 待实机确认 | 角度方案须确认积木输出为角度 | 按模型与课堂测试设置 |
| 基准姿态 | 待实机确认 | 移动主控安装位置后重新设置 | 直立静止时记录 |

:::note
板载姿态传感器的可用输出取决于扩展库。若库提供俯仰角或横滚角，可比较当前角度与直立基准的偏差；若仅提供加速度或其他数据，需按模块文档选择对应方法。静态倾斜不应仅凭陀螺仪角速度判断。
:::

:::caution
测试时手扶模型，小角度缓慢倾斜，避免模型跌落。不要将课堂模型用于真实建筑安全判断。
:::

## 运行测试

完成程序后，按以下顺序测试：

1. **启动检查**：连接设备并下载已验证程序，确认初始化状态与屏幕标签正确。
2. **模型直立放置**：显示正常，读数稳定在基准附近。
3. **缓慢向选定方向倾斜并扶正**：超过阈值时提醒，扶正后解除。
4. **向另一方向倾斜**：验证当前方案覆盖的方向，记录盲区。
5. **复测与记录**：改变一个条件后重复测试，记录输入、输出与结果。

如果出现“直立时也报警”，重新记录基准，检查主控固定和轴选择。

如果出现“某方向倾斜不报警”，检查检测轴；如需全方向检测，增加第二轴判断。

## 扩展挑战

### 挑战一：增加持续倾斜判断

增加持续时间判断，仅在倾斜保持一段时间后提醒。比较轻微晃动与持续倾斜时的结果。

### 挑战二：比较不同底座

保持塔身相同，改变底座宽度。手扶模型进行小角度测试，比较结构稳定性。

### 挑战三：记录最大偏差

用变量记录本次测试中最大的姿态偏差。复位后重复测量，并解释差异。

### 挑战四：比较两个方向的倾斜

分别向两个方向缓慢倾斜，确认各自对应的姿态字段。设计能够识别两个方向的提示逻辑。

### 挑战五：设计分级提醒

为轻微倾斜和明显倾斜设置不同提示。先确认阈值与模型稳定性的关系，再进行测试。

## 扩展知识

### 角度与角速度有什么区别？

角度描述朝向或倾斜程度，角速度描述旋转快慢。物体倾斜后保持静止，角速度仍可能接近零，因此不能只用角速度判断静态倾斜。

### 为什么需要直立基准？

主控安装方向会影响姿态读数。先记录模型直立时的值，再比较偏差，有助于区分安装差异与实际倾斜。

### 什么影响塔架稳定性？

底座宽度、重心位置和连接牢固程度都会影响稳定性。改变一个结构条件，再进行小角度测试，可以比较改进效果。
