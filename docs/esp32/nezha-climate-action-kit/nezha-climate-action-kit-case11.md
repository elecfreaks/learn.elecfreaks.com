# 案例十一：城市热岛探测车

## 案例简介

阳光下、树荫里和建筑旁的环境温度是否相同？本案例搭建移动式环境探测车，携带温湿度传感器，并使用 **Nezha ESP32** 的光敏传感器，在多个位置停车采样。学生记录地点与测量条件，比较校园微环境，初步探究与热岛现象有关的问题。

学生将通过搭建、编程和测试，把观测结果与模型的显示或动作联系起来，学习用数据解释现象。

通过本案例，学生可以结合课堂观察与工程实践，思考如何利用技术改善校园和城市环境。

## 教学目标

完成本案例后，学生能够：

1. 控制车辆安全移动，完成定点停车采样。
2. 记录温度、湿度与光照相对值，比较多个地点。
3. 辨别局部环境差异与城市尺度热岛结论的区别。
4. 根据测试结果调整参数，经历“设计—编程—测试—改进”的工程实践过程。

## 课程引入

让学生回想夏天经过树荫与水泥地的感受，预测哪些地点可能更热。设计一条短路线，比较预测和实测结果。提醒：这是一项校园微环境调查，少量点位或一次测量不足以证明城市热岛强度。

本节课中，我们将扮演“城市环境设计师”，搭建城市热岛探测车，用实际观测检验自己的设计。

## 学习探究

在开始搭建前，可以分组讨论以下问题：

1. 边走边测与停车等待后测量，有什么差别？
2. 传感器被太阳直晒，会影响温度读数吗？
3. 不同小组在不同时间测量的数据是否可直接比较？
4. 你会怎样记录测试条件，说明结果是否符合预期？
5. 如果把模型应用到真实环境，还需要考虑哪些因素？

搭建时重点检查：

- 搭建平衡底盘，固定主控、电源与线材，防止卷入车轮。

- 规划平整、远离道路与台阶的路线；教师监督户外测试。

### 1. 启动初始化

<!-- 图片占位符：启动初始化程序截图 -->

程序启动后将执行以下操作：

1. 先完成低速前进、转向与停止，控制方式以实际程序为准。
2. 初始化屏幕与数据变量，避免沿用上一次运行的状态。

| 第 2 行 | 温度、湿度与光照相对值 |
| 第 3 行 | 运行状态 |
| 第 4 行 | 地点编号 / 采样状态 |

### 2. 循环检测与控制

<!-- 图片占位符：循环检测与控制程序截图 -->
<!-- 建议文件名：./images/urban-heat-island-rover-program-main.png -->

在 `forever` 循环中，系统会持续执行以下任务。

#### 移动控制

- 先完成低速前进、转向与停止，控制方式以实际程序为准。

#### 采样状态

- 停车后进入采样状态，等待传感器适应环境。

#### 记录与显示

- 记录地点编号、时间、温湿度及光照；可选上传平台。

#### 下一点

- 确认记录完成后移动至下一点，不将移动中的读数混入定点比较。

### 3. 关键参数

| 参数 | 示例值 | 含义 | 调整建议 |
| --- | ---: | --- | --- |
| 移动速度 | 待实机确认 | 转向与停止先单独验证 | 从低速调试 |
| 适应时间 | 待实机确认 | 不指定未经验证的统一等待秒数 | 以读数趋稳及传感器响应为准 |
| 采样策略 | 待实机确认 | 尽量缩短不同点位的测量时间差 | 相同位置与高度重复测量 |

:::note
车辆负责移动，传感器负责采样。温湿度探头需要适应环境，因此应在停车并等待读数趋于稳定后记录。车身热源、日晒与采样时间都会影响比较；测得的是传感器附近空气状态，不等同于路面表面温度。
:::

:::caution
先低速验证转向和停止，再进入平整的测试区域；户外活动由教师监督，远离道路、台阶和水边。
:::

## 运行测试

完成程序后，按以下顺序测试：

1. **启动检查**：连接设备并下载已验证程序，确认初始化状态与屏幕标签正确。
2. **架空车轮或在安全测试区验证**：前进、转向、停止方向正确。
3. **同一地点连续测量**：读数趋稳后再记录，说明波动范围。
4. **比较日晒处与树荫处并复测**：使用相同方法，记录影响因素，不只比较单个数字。
5. **复测与记录**：改变一个条件后重复测试，记录输入、输出与结果；结束时停止执行器。

如果出现“温度总偏高”，检查探头是否直晒、紧贴热源或尚未稳定。

如果出现“车辆方向不正确”，检查左右电机接线和正反转定义，重新验证停止指令。

## 扩展挑战

### 挑战一：交换采样顺序

先测日晒处再测树荫处，然后交换顺序复测。讨论时间变化是否影响两处的比较。

### 挑战二：制作校园微环境地图

将采样地点、时间及温湿度数据标在校园地图上。注明日晒、地面材料与探头高度。

### 挑战三：增加重复测量

每个地点重复测量多次，记录平均水平与波动。比较单次结果与重复测量结果的差异。

### 挑战四：比较探头安装位置

比较不同探头安装位置，保持其他条件尽量一致。观察电机热量、日晒与通风造成的影响。

### 挑战五：接入 IoT 看板

将地点编号及环境数据上传 IoT 平台。确认断网时车辆可以停止，本地采样不依赖上传成功。

## 扩展知识

### 什么是城市热岛现象？

城市部分区域可能比周边地区更热，这与地表材料、植被、建筑和人为热排放等因素有关。校园少量点位的观测只能用于讨论局部差异。

### 为什么停车后再测量？

温湿度传感器需要时间适应环境。移动中采样还可能受气流、电机热量和位置变化影响，停车并等待读数趋稳更便于比较。

### 空气温度等于地面温度吗？

温湿度传感器通常测量探头附近的空气状态，不能直接代表路面表面温度。测量时应保持探头通风，并记录日晒条件。
