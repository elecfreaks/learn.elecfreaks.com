# 智控马达拓展盒

## 简介

智控马达拓展盒专为自研主控盒设计的硬件外设，旨在通过IIC总线扩展主控的电机驱动能力，提供便捷、安全的四路电机控制方案。


## 特性

- 精准的主控适配：专为自研主控盒（ESP32、哪吒V2）量身定制，摒弃冗余接口，通过IIC总线实现极简通信，释放主控IO资源。
- 高集成度的电源与驱动：将Type-C充电、自带电池、4路大电流驱动与状态指示灯高度集成，解决移动设备的供电痛点。
- 开放且安全的底层架构：提供清晰的寄存器映射与底层驱动库，同时内置多重硬件级安全保护机制，兼顾了极客开发的灵活性与工业级的可靠性。
