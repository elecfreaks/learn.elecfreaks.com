# 案例：AI 小球搜寻小车

用 Nezha ESP32 搭建小车，发现小球、靠近并驱动夹爪夹取

## 案例简介

机器人怎样找到散落在场地上的小球，并把它夹起来？本案例使用 **Nezha ESP32 多功能主控盒**、三个智能积木马达和夹爪结构搭建小车。AI Lens Pro 负责获取小球的位置和大小，主控盒负责控制左右轮与夹爪。

小车先低速转动搜寻目标，发现后调整方向并接近；小球进入标定的夹取位置时，小车停车，连续确认目标位置，再驱动夹爪闭合。夹取动作结束后保持停车，由学生检查是否真正夹住小球。

## 教学目标

1. 学会判断图像中是否包含小球。
2. 读取指定目标的 X 坐标和大小。
3. 使用左右轮差速完成搜寻、对准和接近，再控制夹爪执行夹取。
4. 用任务状态组织多步动作，区分“动作执行完毕”与“夹取成功”。
5. 通过标定与重复试验，调整停车阈值、夹爪行程和目标丢失处理。

## 硬件连接

1. 关闭电源，用积木搭建双轮差速底盘，将 Nezha ESP32 固定在底盘中央。
2. 按下表连接摄像头和三个智能积木马达，夹爪安装在车头中央，开口朝前。
3. 将 AI Lens Pro 固定在夹爪上方，镜头略向下，确保接近阶段仍能看到夹爪入口处的小球。
4. 调整夹爪高度与开口，让小球能够进入两指之间；选用可在电机停止后保持位置的自锁传动结构。
5. 先开启摄像头，待进入主界面后，再启动主控盒上的项目。

| 模块 | 主控盒接口 | 用途 |
| --- | --- | --- |
| AI Lens Pro | 蓝色 IIC 接口 | 获取小球识别结果 |
| 左轮智能积木马达 | M1 | 左轮速度控制 |
| 右轮智能积木马达 | M2 | 右轮速度控制 |
| 夹爪智能积木马达 | M3 | 按标定角度张开、闭合 |

<!-- 图片占位：Nezha ESP32 的 IIC、M1、M2、M3 接线及夹爪安装 -->

**注意：** 本方案使用支持角度反馈的智能积木马达，普通直流电机不能直接替换夹爪电机。先架空车轮检查方向，再低速测试夹爪行程；闭合终点应留有余量，不让电机持续顶住机械限位。测试时保持手指远离夹爪。

本案例使用 **MicroBlocks**。主控盒的连接、固件与项目存储方式可参考 [Nezha ESP32 使用教程](../../../../esp32/nezha-for-esp32-board.md)。

1. 打开 [MicroBlocks 平台](https://microblocksfun.cn/run/microblocks.html)，新建“小球搜寻与夹取”项目。
2. 使用 USB Type-C 数据线连接电脑与 Nezha ESP32，在平台中选择对应设备。
3. 在“添加积木库”中找到恩孚科技对应的 **Nezha ESP32 板载传感器、运动控制**积木，以及行星系列的 **AI 摄像头 Pro** 积木。
4. 核对当前库能否提供图像刷新、小球判断、目标 X 坐标和大小、M1～M3 速度控制、M3 角度控制及角度反馈。
5. 先分别运行“读取小球数据”“左右轮低速运动”“夹爪张开与闭合”三个小测试，再组合完整程序。

**说明：** 当前[软件库说明](./library-documentation.md)将 AI 摄像头 Pro 的 MicroBlocks 库标注为“待上架”。下文提供教学逻辑，积木名称和菜单位置需以实际安装版本为准；若库尚不可用，应先取得兼容库后再实机搭建程序。

## 积木使用方法

### 1. 判断是否发现小球

初始化并切换到**小球识别**后，每轮先获取一帧图像，再判断图像中是否包含任意小球。未识别到目标时，不使用目标坐标控制前进，也不触发夹取。

### 2. 获取小球位置与大小

使用 **从图像中获取最大小球的 X 坐标/大小值**。选择“最大”时按横向像素宽度选择目标；“大小”返回的是目标纵向像素尺寸，两者含义不同。

本案例以 640 × 480 坐标为例，X = 320 为水平中心，280～360 为初始对准范围。先确认当前库实际返回的坐标尺度；夹爪中心若与画面中心不一致，应以实测夹取中心 **Cx** 调整判断范围。

将小球放在张开的夹爪内、能够夹住的位置，记录它的 X 坐标和图像大小，作为夹取位置的标定依据。下文暂用 **Cx = 320、T = 120 px**，就位大小范围为 **T～T + 20 px**，这些数值都需要按实物调整。

**注意：** 判断任意小球后读取“最大”目标，可使检测与取值保持一致。若同时放入多个不同颜色的小球，仅判断“有红球”并不能保证读取到的最大目标就是红球。

<!-- 图片占位：小球检测、最大目标坐标和大小积木 -->

### 3. 控制车轮与夹爪

将 M1、M2 分别设为左右轮，用速度控制前进和转向。左右电机可能镜像安装，先约定“正速度表示该侧车轮向前”，在自定义积木中统一修正方向。

M3 使用角度控制。将夹爪定位到张开位置，按当前库的角度基准记录 **打开角度**，再低速调试并记录 **闭合角度**。两个角度必须使用同一基准，不能把相对转角与绝对角度混用；再次启动前检查实际位置。

### 4. 显示状态并读取按键

在主控盒屏幕上更新状态、X 坐标、大小和 M3 角度。程序内约定 **A 键开始、B 键停止、C 键张开夹爪并复位**，这里使用的是项目自定义按键输入，应与系统菜单操作区分。

## 示例程序：搜寻、接近与夹取

### 程序思路

程序分为“待机”“搜寻接近”“就位确认”“夹取中”“待确认”“停止”和“张开中”。使用一个主循环管理状态，只有切换到夹取中时才发送一次闭合指令，避免在循环中反复夹紧。

先完成一次夹取并停车，再由学生检查结果。基础任务不自动搬运、不自动松爪，也不自动开始下一次搜寻。

### 速度设置

| 判断条件 | 左轮速度 | 右轮速度 | 动作 |
| --- | ---: | ---: | --- |
| 暂未发现目标 | 12% | -12% | 原地右转，最多连续搜寻 20 轮 |
| X 小于 Cx - 40，且尚未过近 | 0% | 15% | 向左对准 |
| X 大于 Cx + 40，且尚未过近 | 15% | 0% | 向右对准 |
| 已对准且大小小于 T | 12% | 12% | 低速接近 |
| 已对准且大小为 T～T + 20 | 0% | 0% | 停车并连续确认位置 |
| 大小大于 T + 20 | 0% | 0% | 停止，提示重新摆放 |
| 夹取中、待确认、停止或张开中 | 0% | 0% | 车轮保持停止 |

| 夹爪参数 | 初始设置 | 调试方法 |
| --- | --- | --- |
| 打开角度、闭合角度 | 按实物标定 | 开口能容纳小球，闭合后能固定海绵球且不顶限位 |
| M3 动作速度 | 10% | 从低速开始，按负载调整 |
| 到位角度允许误差 | ±5° | 按反馈精度调整，连续三轮满足才算到位 |
| 单次动作等待上限 | 3000 毫秒 | 按实测行程调整，超时停止 M3 |

### 程序搭建

创建变量 **状态**、**X**、**大小**、**连续丢失次数**、**就位次数**、**到位次数**、**动作开始时间**、**Cx**、**T**、**打开角度**、**闭合角度**。

将“设置左右轮速度”“停止全部电机”“张开夹爪”和“闭合夹爪”封装成自定义积木。下面的文字表示搭建逻辑，需映射到实际库中的积木；夹爪运动采用发送目标后轮询角度的方式，不使用长时间阻塞整个主循环的等待积木。

```text
当程序启动
    初始化 AI Lens Pro
    切换功能为小球识别
    设置 Cx = 320，T = 120（按标定调整）
    设置 打开角度、闭合角度 = 各自的标定值
    设置 连续丢失次数 = 0，就位次数 = 0，到位次数 = 0
    停止 M1、M2、M3
    设置 状态 = 停止
    显示“请按 C 键张开并复位”

重复执行
    如果 检测到 B 键按下事件
        停止 M1、M2、M3
        设置 状态 = 停止
    否则如果 检测到 C 键按下事件 且 状态为停止或待确认
        停止 M1、M2
        以 10% 速度发送 M3 打开角度目标（仅发送一次）
        设置 到位次数 = 0，动作开始时间 = 当前时间
        设置 状态 = 张开中
    否则如果 检测到 A 键按下事件 且 状态为待机
        设置 连续丢失次数 = 0，就位次数 = 0
        设置 状态 = 搜寻接近

    如果 状态为搜寻接近或就位确认
        从 AI Lens Pro 获取一帧图像
        如果 图像中包含任意小球
            设置 连续丢失次数 = 0
            设置 X = 最大小球的 X 坐标
            设置 大小 = 最大小球的大小
            如果 大小 > T + 20
                停止全部电机，设置 状态 = 停止
                显示“目标过近，请重新摆放”
            否则如果 X < Cx - 40
                设置 就位次数 = 0，状态 = 搜寻接近
                设置左轮速度 0%，右轮速度 15%
            否则如果 X > Cx + 40
                设置 就位次数 = 0，状态 = 搜寻接近
                设置左轮速度 15%，右轮速度 0%
            否则如果 大小 < T
                设置 就位次数 = 0，状态 = 搜寻接近
                设置左右轮速度均为 12%
            否则
                停止左右轮，设置 状态 = 就位确认
                就位次数增加 1
                如果 就位次数 ≥ 3
                    以 10% 速度发送 M3 闭合角度目标（仅发送一次）
                    设置 到位次数 = 0，动作开始时间 = 当前时间
                    设置 状态 = 夹取中
        否则
            设置 就位次数 = 0，状态 = 搜寻接近
            连续丢失次数增加 1
            如果 连续丢失次数 ≤ 20
                设置左轮速度 12%，右轮速度 -12%
            否则
                停止全部电机，设置 状态 = 停止

    否则如果 状态为夹取中或张开中
        停止 M1、M2
        根据状态，设置 目标角度 = 闭合角度或打开角度
        读取 M3 当前角度
        如果 当前角度与目标角度的差的绝对值 ≤ 5°
            到位次数增加 1
        否则
            设置 到位次数 = 0
        如果 到位次数 ≥ 3
            停止 M3（自锁夹爪保持位置）
            如果 状态为张开中
                设置 状态 = 待机
            否则
                设置 状态 = 待确认
                显示“夹取动作结束，请检查小球”
        否则如果 当前时间 - 动作开始时间 > 3000 毫秒
            停止全部电机，设置 状态 = 停止
            显示“夹爪未到位，请检查行程”
    否则
        停止 M1、M2

    更新屏幕上的状态、X、大小和 M3 角度
    等待 100 毫秒
```

**程序说明：** 搜寻最多连续进行 20 个未检出目标的循环，随后停车。就位确认和夹爪到位均采用三轮确认，但电机角度到位只能说明动作完成，不能证明小球已夹住；若要自动判断成功，可在拓展中增加触碰或夹爪开口反馈。

小球大小用于估计接近程度，不能直接换算成厘米。若小球尚未进入夹爪就被遮挡，应先调整镜头和夹爪结构，再重新标定，不能把目标丢失直接作为闭爪条件。B 键在每轮开始读取，响应时间还受图像通信和电机指令耗时影响。

## 运行与保存程序

1. 使用 USB Type-C 数据线连接 Nezha ESP32，在 MicroBlocks 中连接设备并保存电脑端项目。
2. 架空车轮，检查前进、左右转向和 B 键停止；单独标定 M3 的打开、闭合角度及到位等待上限。
3. 将小车放到开阔地面，按 C 键张开并复位，再把一个海绵球放到前方，按 A 键启动。
4. 确认小车能够对准、停车并闭爪；检查是否夹住，再按 C 键放开并复位。动作过程中可按 B 键停止。
5. 使用主控盒程序管理页面的“另存为”保存需要保留的程序；重启后按主控盒教程选择并运行已保存项目，重新确认夹爪位置后测试。

### 分步验证

| 测试任务 | 观察结果 | 记录内容 |
| --- | --- | --- |
| 将小球放在左、中、右侧 | 小车先对准，再低速接近 | 是否转向正确 |
| 将小球放在标定夹取位置 | 车轮停止，连续确认后才闭爪 | X、大小、停车误差 |
| 在接近或就位时移走小球 | 不执行闭爪，进入有限次搜寻 | 是否出现误夹 |
| 夹爪不能在等待上限内到位 | 停止 M3，显示检查提示 | 角度、耗时与机构问题 |
| 重复完成 5 次夹取 | 逐次检查是否真正夹住 | 成功次数与失败原因 |

## 效果演示

按 C 键复位、A 键开始后，小车搜寻并对准小球，低速接近到标定位置，停车确认后驱动夹爪闭合。夹取动作结束后保持停车，屏幕提示检查结果；持续未找到目标或夹爪未到位时停止。

## 思考与拓展

1. 为什么要先对准小球、停车确认，再闭合夹爪？
2. 同一距离下，大球和小球的图像大小是否相同？
3. 电机已经到达闭合角度，为什么仍可能没有夹住小球？
4. 怎样迁移[颜色分拣台](./color-recognition.md)的任务状态，完成夹取后的分类放置？
5. 结合[视觉巡线](./line-following.md)，设计“沿线到达搜寻区—停车切换小球识别—夹取—按键确认后返回”的分阶段任务。
