# 案例：AI 人脸追踪云台

让镜头跟随人脸转动，把人脸保持在画面中央

## 案例简介

视频通话时，如果镜头能够跟随人的位置转动，画面会怎样变化？本案例使用 AI Lens Pro 检测人脸，读取人脸中心坐标，再通过两个电机调整云台的水平和俯仰方向。

人脸偏离画面中心时，云台向对应方向转动；进入中心范围后停止；没有检测到人脸时，两个电机停止。本案例依靠人脸位置进行追踪，无需预先学习姓名。

<!-- 图片占位：AI 人脸追踪云台成品图 -->

## 教学目标

1. 区分人脸检测与已学习人脸的身份识别。
2. 学会读取人脸中心 X、Y 坐标。
3. 使用中心范围和分档速度控制双轴云台。
4. 为目标丢失和机械行程设置停止条件。

## 硬件连接

1. 关闭电源，将 micro:bit 安装到哪吒 Pro 多功能扩展盒上。
2. 将 AI Lens Pro 固定在云台上，接到扩展盒的 **IIC 接口**。
3. 水平转动电机接到 **M1**，俯仰电机接到 **M2**。
4. 将云台置于中间位置，给线材留出转动余量，检查各轴的可用行程。
5. 先开启 AI Lens Pro，待进入主界面后再启动主控程序。

**注意：** 先以低速分别测试两个轴，确认正负速度对应的运动方向。设置合理的角度限位，避免镜头转到结构尽头或缠绕线材。

## 软件准备

1. 打开 [MakeCode 网站](https://makecode.microbit.org/)，新建“AI 人脸追踪云台”项目。
2. 在 **扩展（Extensions）** 中添加 `planetX-AI` 和 `nezha pro`；参考程序的电机库为 `pxt-nezha2`。
3. 找到人脸识别、刷新图像、电机启动和停止积木。

## 积木使用方法

### 1. 判断是否检测到人脸

每轮使用 **从 AI 摄像头 Pro 获取一帧图像** 更新结果，再使用 **图像中包含人脸** 判断。只有检测到人脸时才读取坐标；否则停止两个电机。

### 2. 获取人脸中心坐标

使用 **从图像中获取人脸的 X 坐标/Y 坐标值**。多人同时出现时，默认读取距离画面中心最近的人脸，因此测试时先让一人进入画面。

将人脸放在画面正中央，记录返回值，作为 **Cx**、**Cy**。本页以 640 × 480 坐标的 **Cx = 320、Cy = 240** 为初始值；如果当前固件返回不同坐标尺度，需按实测中心值同步调整阈值。

### 3. 控制两个轴

使用电机正负速度控制方向，速度为 0 或使用停止积木时停止。下面沿用参考程序的电机方向约定：M1 正速度使镜头向左，M2 负速度使镜头向上；如果机构安装相反，应反转对应轴的速度符号。

## 示例程序：双轴分档追踪

### 程序思路

计算水平误差 **Ex = X - Cx**、垂直误差 **Ey = Y - Cy**。误差较大时较快转动，接近中心时减速，进入中心范围后停止。每轮只获取一帧，让两个轴使用同一帧的人脸位置。

### 速度设置

| 轴向误差 | 电机速度 | 动作 |
| --- | ---: | --- |
| Ex ≤ -40 | M1：15% | 较快向左 |
| -40 < Ex ≤ -10 | M1：5% | 缓慢向左 |
| -10 < Ex < 10 | M1：0% | 水平停止 |
| 10 ≤ Ex < 40 | M1：-5% | 缓慢向右 |
| Ex ≥ 40 | M1：-15% | 较快向右 |
| Ey ≤ -30 | M2：-30% | 较快向上 |
| -30 < Ey ≤ -10 | M2：-10% | 缓慢向上 |
| -10 < Ey < 10 | M2：0% | 俯仰停止 |
| 10 ≤ Ey < 30 | M2：10% | 缓慢向下 |
| Ey ≥ 30 | M2：30% | 较快向下 |

这些数值用于初始调试；不同传动结构需要降低速度或调整误差范围。

### 程序搭建

可以打开已有的 [人脸追踪云台 MakeCode 参考程序](https://makecode.microbit.org/_167gxtLXVfkv)。原程序使用中心坐标约为 (160, 120) 的阈值，且没有“未检测到人脸时停止”的分支。使用时应先核对设备返回的坐标尺度，并补充停止和限位逻辑。

下面是建议的积木搭建逻辑：

```text
当程序启动
    初始化 AI Lens Pro
    切换功能为人脸识别
    设置 Cx = 320，Cy = 240（按实测调整）
    停止 M1、M2

重复执行
    从 AI Lens Pro 获取一帧图像
    如果 图像中包含人脸
        设置 Ex = 人脸 X 坐标 - Cx
        设置 Ey = 人脸 Y 坐标 - Cy
        根据水平误差表设置 M1 速度
        根据垂直误差表设置 M2 速度
        如果某轴已到行程边界且指令仍朝边界外运动
            停止该轴
    否则
        停止 M1、M2
    等待 50 毫秒
```

<!-- 图片占位：含人脸丢失停止与限位处理的完整积木程序图 -->

**程序说明：** 中心范围可以减少轻微识别波动引起的来回转动。限位可使用电机角度反馈实现：先确定每个轴的起始角度与允许角度范围，到达边界后仅允许向范围内部转动。

## 下载程序

1. 用 USB 数据线连接电脑与 micro:bit，在 MakeCode 中下载程序。
2. 先开启摄像头，再运行云台程序，让一人位于画面中央，核对 Cx、Cy。
3. 分别向左右、上下缓慢移动，观察追踪；离开画面，确认两个轴停止。

## 效果演示

人脸在画面中移动时，云台分档调整水平和俯仰方向，使人脸回到中心附近。人脸离开画面或电机到达行程边界时，对应电机停止。

复用目标位置指示器的坐标区间，将箭头提示改成电机方向；在单轴有效后增加俯仰轴，为后续小车对准小球积累闭环调试经验。

## 思考与拓展

1. 中心范围太小，为什么容易出现来回抖动？
2. 如果镜头越转越偏，应检查坐标还是电机方向？
3. 多人同时出现时，云台为什么可能切换追踪目标？
4. 尝试让电机速度随位置误差连续变化，比较与分档控制的差异。
