# 快速入门


## **操作说明**



- 单击电源键0\.3秒开机

- Makecode平台使用：

    - 打开平台链接，并新建项目：https://makecode.microbit.org

    - 点击拓展，搜索planetX\-AI，点击planetX\-AI库即可完成拓展库添加

    - 在左侧积木库找到planetX\-AI选项卡，拖拽使用其中积木

    - 编程完成后将程序下载到micro:bit中运行

- Microblocks平台使用（待上架）

    - 打开平台链接：https://microblocksfun.cn/run/microblocks.html
