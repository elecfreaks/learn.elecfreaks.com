# 快速入门

先认识 AI Lens Pro，并尝试观察画面；准备好主控设备后，再进入图形化编程。低年级学生建议在教师协助下操作。
![器件位置标注图](https://wiki-media-ef.oss-cn-hongkong.aliyuncs.com/docs/microbit/sensor/planet-x-sensors/ai-lens-pro/ai-lens-pro-03.png)

## 准备材料

| 材料 | 用途 |
| --- | --- |
| AI Lens Pro | 观察图像和使用设备功能 |
| 光线充足的桌面和一个积木模型 | 作为观察对象 |
| micro:bit 与 Nezha 拓展板或 Nezha2 拓展板，或 Nezha ESP32 主控盒；连接线和电脑 | 后续编程时按案例选择使用 |

## 第一次观察

1. 找到摄像头、屏幕和电源键，按电源键开机。
2. 把积木模型放在镜头前，观察屏幕上的画面。移动模型，看看它在画面中的位置如何变化。
3. 尝试只改变距离，观察模型在画面中的大小；再把模型放回原处，试着改变角度。
4. 说一说或写下来：我改变了什么？画面发生了什么变化？

**完成检查：** 屏幕正常显示，移动物体时画面随之变化。若没有画面，先检查设备是否开机、是否有电，以及镜头是否被遮挡；仍无法解决时请教师协助。

## 连接主控并准备编程

1. 按案例选择主控。使用 Nezha 拓展板或 Nezha2 拓展板时，关闭电源并安装 micro:bit；使用 Nezha ESP32 主控盒时，无需安装 micro:bit。
2. 将 AI Lens Pro 接到所选设备的 IIC 接口；检查连接后，先开启摄像头，再启动主控。
3. 使用 micro:bit 时，打开 [MakeCode](https://makecode.microbit.org/)，新建项目，在“扩展”中搜索 `planetX-AI` 并添加。
4. 在左侧积木分类中查找 AI 摄像头相关积木。选择适用于所选主控的案例，按接线和步骤搭建程序。Nezha ESP32 的编程环境与 micro:bit 不同，摄像头库的使用方式需待验证。

可以从[积木分类助手](./self-learning-classification.md)开始，认识类别与样本；学习坐标和电机控制后，再探索[人脸追踪云台](./face-detection.md)。

## 遇到问题时

| 现象 | 先检查 |
| --- | --- |
| 屏幕不亮 | 电源和电量；请教师协助检查充电。 |
| 看不到物体 | 镜头是否被遮挡、物体是否在画面内、光线是否充足。 |
| 找不到扩展 | 网络是否可用、搜索名称是否输入正确；仍找不到时请教师核对库的发布状态。 |
| 主控没有识别结果 | 先检查供电和 IIC 连接，再按案例检查初始化、功能模式和图像刷新。 |

## 给教师的建议

首次体验可安排为观察与表达活动，不要求学生立即搭建程序。可让两人一组轮流操作和记录，鼓励学生一次只改变距离或角度，并描述画面变化。优先使用积木等物品作为观察对象；拍摄人物前应遵循学校的告知和授权要求。
