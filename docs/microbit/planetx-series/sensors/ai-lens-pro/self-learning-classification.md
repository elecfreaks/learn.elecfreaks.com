# 案例：AI 积木分类助手

教摄像头认识两种积木，再测试它能否区分

## 案例简介

如果摄像头的预置模型不认识我们的积木模型，可以自己教它吗？本案例使用 AI Lens Pro 的自学习功能，把两种外观不同的积木模型分别学习为 ID 1 和 ID 2，再通过 micro:bit 显示识别到的类别编号。

先学习正面样本，再补充侧面、不同距离和背景下的样本，比较分类表现，体验训练数据如何影响结果。

<!-- 图片占位：AI 积木分类助手与两种积木模型 -->

## 教学目标

1. 建立自定义类别与 ID 的对应关系。
2. 学会使用按键采集图像中心对象。
3. 获取已学习对象的 ID 和置信度。
4. 用未参与学习的样本测试分类效果。

## 硬件连接

1. 关闭电源，安装 micro:bit，将摄像头接到扩展板的 **IIC 接口**。
2. 固定镜头与展示台，让待学习物体位于画面中心。
3. 先开启 AI Lens Pro，再运行主控程序。
4. 学习和测试时，每次只放一个模型，避免手掌或其他物体挡住主体。

## 软件准备

本案例使用 **Microsoft MakeCode** 图形化编程平台。

1. 打开 [MakeCode 网站](https://makecode.microbit.org/)，新建“AI 积木分类助手”项目。
2. 在 **扩展（Extensions）** 中搜索 `planetX-AI`，添加 AI Lens Pro 扩展库。
3. 在工具栏中找到 **AI Lens Pro** 的基础设置、自学习积木，以及 micro:bit 的按键事件积木。
4. 约定 **ID 1 = 模型 A，ID 2 = 模型 B**。

## 积木使用方法

### 1. 学习图像中心的对象

初始化并切换到**自学习（特征学习）**。使用 **学习图像中心的对象为 ID [1/2]** 采集当前对象。将同一模型换角度后仍学习为同一个 ID，以补充该类别样本。

### 2. 判断结果并读取置信度

先获取一帧图像，再用 **图像中包含已学习对象 [0]** 判断任意已学习对象；参数 0 在这个判断积木中表示“任意”。有效时再读取对象的 **ID** 和**置信度**。

`planetX-AI` v1.1.1 的置信度按 0～1 返回，本例用 **0.8** 作为起始阈值。若使用其他版本，应先查看实际输出并核对尺度，再设阈值。

### 3. 清除指定类别

**清除已学习的对象 [1/2]** 用于重新训练指定类别。该积木的参数 0 表示清除所有类别，含义与判断积木不同；本例不在启动时自动清除数据。

## 示例程序：按键学习与类别显示

### 程序思路

A 键学习当前模型为 ID 1，B 键学习为 ID 2；学习时短暂暂停识别。循环中只有 ID 为 1 或 2 且置信度达到阈值才显示编号，其余情况显示问号或清屏。

### 操作设置

| 操作或结果 | 程序行为 |
| --- | --- |
| 按 A 键 | 当前中心对象学习为 ID 1 |
| 按 B 键 | 当前中心对象学习为 ID 2 |
| ID 为 1 或 2，且置信度达到阈值 | 显示对应编号 |
| 结果置信度不足或其他 ID | 显示问号 |
| 未识别到已学习对象 | 清屏 |

### 程序搭建

以下文字为积木搭建逻辑：

```text
当程序启动
    初始化 AI Lens Pro
    切换功能为自学习
    设置 学习中 = 0，阈值 = 0.8

当 A 键按下
    如果 学习中 = 0
        设置 学习中 = 1
        学习图像中心的对象为 ID 1
        等待 1000 毫秒
        设置 学习中 = 0
当 B 键按下
    如果 学习中 = 0
        设置 学习中 = 1
        学习图像中心的对象为 ID 2
        等待 1000 毫秒
        设置 学习中 = 0

重复执行
    如果 学习中 = 0
        从 AI Lens Pro 获取一帧图像
        如果 图像中包含任意已学习对象（参数 0）
            设置 ID = 已学习对象的 ID
            设置 置信度 = 已学习对象的置信度
            如果 (ID = 1 或 ID = 2) 且 置信度 ≥ 阈值
                显示数字 ID
            否则
                显示自定义问号图案
        否则
            清屏
    等待 200 毫秒
```

## 下载程序

1. 使用 USB 数据线连接 micro:bit，下载程序，开启摄像头后启动主控。
2. 放入模型 A，按 A 键采样；更换角度后继续按 A 键。对模型 B 使用 B 键重复操作。
3. 用未参与学习的角度、距离和背景测试，记录正确、错误和未识别次数。

## 效果演示

摄像头学习两类模型后，对满足阈值的结果显示 1 或 2。低置信度结果显示问号，无有效结果时清屏。

## 学习衔接

建议先完成[目标位置指示器](./object-tracking.md)，再进行本课。

选用物品检查员课中模型不认识的两种积木建立类别；沿用观察日记中的距离、角度和光照条件补充样本，再测试未见过的摆放方式。

下一课：[举手计数器](./pose-recognition.md)。

## 思考与拓展

1. 为什么只学习正面样本，侧面测试可能失败？
2. 如果两类模型总是在不同背景上学习，摄像头可能学到什么？
3. 阈值从 0.8 提高到 0.9 后，错误和未识别次数怎样变化？
4. 增加第三类模型时，学习操作和显示逻辑需要怎样调整？
