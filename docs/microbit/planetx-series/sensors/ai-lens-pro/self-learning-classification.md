# 案例：AI 积木分类助手

教摄像头认识两种积木，再测试它能否区分

## 案例简介

如果摄像头的预置模型不认识我们的积木模型，可以自己教它吗？本案例使用 AI Lens Pro 的自学习功能，把两种外观不同的积木模型分别学习为 ID 1 和 ID 2，再通过 micro:bit 显示识别到的类别编号。

先学习正面样本，再补充侧面、不同距离和背景下的样本，比较分类表现，体验训练数据如何影响结果。

## 教学目标

1. 建立自定义类别与 ID 的对应关系。
2. 学会使用按键采集图像中心对象。
3. 获取已学习对象的 ID 和置信度。
4. 用未参与学习的样本测试分类效果。

## 教学信息

| 项目 | 建议 |
| --- | --- |
| 适用对象 | 小学高年级及以上；低年级可在教师协助下完成观察和采样。 |
| 建议课时 | 1～2 课时，每课时约 40～45 分钟；实际时长可按学生经验调整。 |
| 前置经验 | 认识按键、条件判断和循环；能够在教师指导下连接设备。 |
| 核心问题 | 只学习一种摆放方式后，设备还能认出换了角度的模型吗？ |
| 基础成果 | 为两种模型建立类别，并记录测试结果。 |
| 进阶成果 | 使用相同测试条件，比较补充样本前后的结果并解释局限。 |

课前请检查电量、IIC 连接、扩展库和自学习功能。先确认当前版本的学习、清除、结果读取与数据保存方式，再安排学生操作；清除数据前先确认不影响其他小组。

## 硬件连接

1. 关闭电源，将 micro:bit 安装到带 IIC 接口的兼容扩展板，并将摄像头接到扩展板的 **IIC 接口**。
2. 固定镜头与展示台，让待学习物体位于画面中心。
3. 先开启 AI Lens Pro，再运行主控程序。
4. 学习和测试时，每次只放一个模型，避免手掌或其他物体挡住主体。

## 软件准备

本案例使用 **Microsoft MakeCode** 图形化编程平台。

1. 打开 [MakeCode 网站](https://makecode.microbit.org/)，新建“AI 积木分类助手”项目。
2. 在 **扩展（Extensions）** 中搜索 `planetX-AI`，添加 AI Lens Pro 扩展库。
3. 在工具栏中找到 **AI Lens Pro** 的基础设置、自学习积木，以及 micro:bit 的按键事件积木。
4. 约定 **ID 1 = 模型 A，ID 2 = 模型 B**。

## 积木使用方法

### 1. 学习图像中心的对象

初始化并切换到**自学习（特征学习）**。使用 **学习图像中心的对象为 ID [1/2]** 采集当前对象。将同一模型换角度后仍学习为同一个 ID，以补充该类别样本。

### 2. 判断结果并读取置信度

先获取一帧图像，再用 **图像中包含已学习对象 [0]** 判断任意已学习对象；参数 0 在这个判断积木中表示“任意”。有效时再读取对象的 **ID** 和**置信度**。

置信度可作为观察识别结果的参考，但不能直接当作结果一定正确的概率。若要按阈值筛选结果，应先核对当前版本的返回范围和含义，再根据测试结果设置。

<!-- 待确认：planetX-AI v1.1.1 及其他支持版本的置信度量程、含义和合适的示例阈值。原文使用 0.8，未完成实机核验，暂不作为默认参数展示。 -->

### 3. 清除指定类别

**清除已学习的对象 [1/2]** 用于重新训练指定类别。该积木的参数 0 表示清除所有类别，含义与判断积木不同；本例不在启动时自动清除数据。

## 示例程序：按键学习与类别显示

### 程序思路

A 键学习当前模型为 ID 1，B 键学习为 ID 2；学习时暂停读取结果。程序设计上，对有效的类别显示编号，对不符合条件的结果显示问号，无结果时清屏。

### 操作设置

| 操作或结果 | 程序行为 |
| --- | --- |
| 按 A 键 | 当前中心对象学习为 ID 1 |
| 按 B 键 | 当前中心对象学习为 ID 2 |
| 结果有效，ID 为 1 或 2 | 显示对应编号 |
| 结果不符合设定条件或为其他 ID | 显示问号 |
| 未识别到已学习对象 | 清屏 |

### 程序搭建

以下为教学设计逻辑，实际积木名称、学习完成的判断方式和结果有效条件需要按已验证的软硬件版本确定。

```text
当程序启动
    初始化 AI Lens Pro
    切换功能为自学习
    设置 学习中 = 0

当 A 键按下
    如果 学习中 = 0
        设置 学习中 = 1
        学习图像中心的对象为 ID 1
        等待学习完成
        设置 学习中 = 0
当 B 键按下
    如果 学习中 = 0
        设置 学习中 = 1
        学习图像中心的对象为 ID 2
        等待学习完成
        设置 学习中 = 0

重复执行
    如果 学习中 = 0
        从 AI Lens Pro 获取一帧图像
        如果 图像中包含任意已学习对象（参数 0）
            设置 ID = 已学习对象的 ID
            设置 置信度 = 已学习对象的置信度
            如果 ID 为 1 或 2，且结果符合设定的有效条件
                显示数字 ID
            否则
                显示自定义问号图案
        否则
            清屏
    等待 200 毫秒
```

## 下载程序

1. 教师先核验并准备可运行程序，再用 USB 数据线连接 micro:bit、下载程序；开启摄像头后启动主控。
2. 放入模型 A，按 A 键采样；更换角度后继续按 A 键。对模型 B 使用 B 键重复操作。
3. 用未参与学习的角度、距离和背景测试，记录正确、错误和未识别次数。

## 学生任务：测试与改进

1. 选两种外观明显不同的模型，记录 ID 1 和 ID 2 各代表什么。先按教师演示学习每类模型。
2. 准备未用于学习的测试摆放方式，例如新的角度；尽量固定背景和光照，依次测试两类模型，各试 5 次。每次只放一个模型。
3. 记录显示结果：正确、分错或未识别。再放入不属于这两类的第三种物体，观察结果；不要预先假定设备一定会拒绝识别。
4. 补充不同角度的学习样本后，用**同一组测试摆放方式**再次测试并比较。采样与测试分开，才能观察对未见过情况的表现。

| 测试对象及条件 | 预期类别 | 补充样本前：正确／错误／未识别 | 补充样本后：正确／错误／未识别 | 观察 |
| --- | --- | --- | --- | --- |
| 模型 A，新角度 | ID 1 |  |  |  |
| 模型 B，新角度 | ID 2 |  |  |  |
| 未学习的第三种物体 | 不属于 A 或 B |  |  |  |

低年级学生可由教师操作程序，重点描述“看到了什么”；高年级学生自行记录并比较；有经验的学生可控制光照或背景，比较不同采样方案。测试次数是课堂建议，可按时间调整。

## 教师组织与评价

可按导入和演示、分组采样、测试改进、交流四个环节组织。每组可分为操作、记录和观察角色，再轮换。重点观察学生能否说明类别与 ID、区分学习和测试、记录失败现象，以及根据记录提出一次改进；无需只按一次识别成功与否评价。

| 现象 | 排查方向 |
| --- | --- |
| 始终没有结果 | 检查供电、IIC 连接、功能模式和图像刷新。 |
| 两种模型经常混淆 | 检查类别与按键对应关系，保持模型清晰、背景一致，再比较采样角度。 |
| 改进前后结果差别很大 | 检查是否更换了测试条件；记录角度、距离和光照后再比较。 |
| 想重新学习但担心删除他人数据 | 先由教师确认当前类别和清除操作；参数 0 的清除含义与判断积木不同。 |

## 学习衔接

建议先完成[目标位置指示器](./object-tracking.md)，再进行本课。

选用物品检查员课中模型不认识的两种积木建立类别；沿用观察日记中的距离、角度和光照条件补充样本，再测试未见过的摆放方式。

下一课：[举手计数器](./pose-recognition.md)。

## 思考与拓展

1. 为什么只学习正面样本，侧面测试可能失败？
2. 如果两类模型总是在不同背景上学习，摄像头可能学到什么？
3. 在确认置信度量程后，提高阈值会怎样影响错误和未识别次数？
4. 增加第三类模型时，学习操作和显示逻辑需要怎样调整？
