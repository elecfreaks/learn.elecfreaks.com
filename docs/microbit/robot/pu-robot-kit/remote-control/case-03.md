# 案例三：摇杆转向——让 PU 原地转弯

## 案例简介

本案例是手柄遥控系列第三课。双足机器人除了直行和平移，还可以"原地转向"——像人一样转身改变面向。本课在案例二的基础上，仅修改机器人端两个方向分支（SideRight→RightTurn、SideLeft→LeftTurn），让摇杆左右拨动从"平移"变为"原地左右转"。通过"只改两行、体验一种新运动方式"的对比式学习，帮助学生理解不同腿部动作对应不同运动效果，强化"方向参数决定动作类型"的编程认识。

## 课程目标

1. 认识"原地转向"动作：理解左右平移（Side）与原地转向（Turn）在腿部动作上的本质区别；

2. 学会在既有程序上做最小修改（两个方向参数），体会"一行代码改变一种行为"的调试思维；

3. 能通过摇杆左右拨动让 PU 原地左转/右转，并配合前进完成"转弯—直行"的组合操控；

4. 通过对比案例二的程序差异，培养观察差异、举一反三的学习能力。

## 课程引入

上节课 PU 已经能前后左右移动了——但细心的同学会发现：当它走到墙角想换个方向时，只能"横着挪"，很别扭。人有办法：停下脚步，原地转身，面向新方向再出发！今天我们要教 PU 学会"原地转身"：左右拨动摇杆，PU 就在原地掉头转圈。神奇的是，这次我们只需要在昨天的程序里改两行代码就能实现——猜猜是哪两行？

## 学习探究

1. 旧知巩固：回顾案例二机器人端的四分支判断结构，提问："让 PU 向右平移用的是哪个方向参数？它和'向右转'有什么区别？"请学生上台指出 右侧 与 右转 两个选项的位置。

2. 新知识学习——平移与转向：平移（side）是身体朝向不变、向侧面并步移动；转向（turn）是身体原地转动、改变面向，两条腿做"原地踏步转身"动作。演示把机器人端两行 SideRight/SideLeft 改为 RightTurn/LeftTurn，其余代码保持不变。

3. 对比式探究：让学生对照案例二与案例三的机器人端代码，用"找不同"的方式圈出修改的两行，讨论"为什么手柄端代码完全不用动"——因为摇杆数值本身没变，变的只是机器人端对左右值的"翻译方式"。

4. 动手验证：烧录后左右拨动摇杆，观察 PU 原地转向；对比案例二"左右平移"，说说两种操控手感的不同。

## 课堂活动

用胶带贴一个"L"形或"S"形路线，操作员摇动摇杆操控 PU 走完路线，每到转弯处需原地转向 90° 再直行，比比哪个小组转向最准、用时最短。观察员负责记录"转多了/转少了/没转"的情况并反馈给操作员调整。

进阶挑战：试试让 PU 先原地转一整圈再直行出发——把转向步数调到能转 360° 的数值（如 12 步左右，视实际地面与舵机情况调整），实现"转身—出发"的仪式感动作。

## 总结分享

教师总结：本节课只修改了两个方向参数，就让 PU 从"平移"升级为"原地转向"——同一个摇杆、同一份发送程序，改变的只是接收端对数值的"翻译"，这就是模块化分工的好处。至此 PU 已具备直行、后退、平移、转向全套移动能力。下节课我们将换一种"传令"方式：不发数字，发文字消息，让 PU "听懂人话"。
