# 案例四：文字传令——与 PU 对话互动

## 案例简介

本案例是手柄遥控系列第四课。前面三课通过无线电发送的是数字指令（按钮编号、摇杆数值），本课学习发送文字消息：按手柄 micro:bit 板上的 A 键发送 "hello"，按 B 键发送 "dance"，PU 机器人收到文字后分别做出"打招呼"与"跳舞"的回应。学生将理解"数字传令"与"文字传令"的差异，并掌握字符串比较的编程方法，体会让机器人"听懂一句话"的趣味。

## 课程目标

1. 认识文字消息指令：理解无线电不仅能传数字，还能传文字（字符串）；

2. 学会使用手柄端「发送文字消息」积木与机器人端「当收到文字值」事件，建立文字到动作的映射；

3. 理解字符串比较（== 判断"内容是否相同"），能独立编写"收到 hello 打招呼、收到 dance 跳舞"的程序；

4. 通过"对讲机式"人机对话体验，激发编程兴趣，感受文字交互在机器人控制中的应用。

## 课程引入

前面的课程里，我们给 PU 传的一直是"数字暗号"：1 代表直行、2 代表跳跃——PU 很聪明，但好像还"听不懂人话"。今天我们来升级通讯方式：直接给 PU 发一句英文单词，就像用对讲机喊话一样！按 A 键说一声 "hello"，PU 会挥手打招呼；按 B 键说一声 "dance"，PU 会当场跳起舞来。想让 PU 听懂更多的话？学会今天这招，你就能"教"它新单词！

## 学习探究

1. 旧知巩固：回顾案例一机器人端 onControlValueReceived(Button, ...) 的使用，提问"我们如何判断收到的是 1 号还是 2 号指令？"引出 if 比较，为文字比较做铺垫。

2. 新知识学习——文字消息：无线电不仅可以传数字，也可以传文字。手柄端使用「发送文字消息」积木，把一句话（如 "hello"）发送出去；机器人端使用「当收到 text 值」事件接收，收到的内容是一个字符串。演示 A/B 键分别发送 "hello" 与 "dance"。

3. 新知识学习——字符串比较：比较文字要用 ==（如 msg == "hello"），并且文字要加英文双引号。强调"hello 与 hello 相同才算相等，大小写不同都不算"，这是初学者最容易出错的地方。

4. 动手验证：烧录后按手柄 A 键，观察 PU 是否做出打招呼动作（点头挥手）；按 B 键，观察是否跳舞。若 PU 无反应，检查文字是否完全一致（含大小写、无多余空格）。

## 课堂活动

组织一场"PU 对话表演赛"：每组给 PU 设计一段 2~3 句的"台词脚本"（只能使用已学的文字关键词），一边按键发送、一边解说 PU 的回应，看看哪组能让 PU 的表演最连贯、最有故事性。其他组观察并评价：PU 的回应是否和发送的文字对应？

进阶挑战：让 PU 多学一个词——手柄端增加"当 A+B 同时按下"事件（Button.AB），发送 "jump"；机器人端增加 else if (msg == "jump") 分支，让 PU 听到 jump 就跳跃。注意两端代码要一起修改。

## 总结分享

教师总结：数字指令适合"动作编号"，文字指令适合"看得懂的命令"——本课用字符串比较让 PU "听懂"了两个单词，实现了"发一句话、做一个动作"的人机对话。想一想：如果文字里夹了空格或大小写不同，PU 还认得出吗？下节课我们暂时放下摇杆和按键，试试用身体的倾斜来指挥 PU——把 micro:bit 变成一只"方向盘"！
