# 案例五：体感操控——倾斜手柄指挥 PU 转弯

## 案例简介

本案例是手柄遥控系列第五课。前几课用按键和摇杆控制，本课引入 micro:bit 内置的加速度传感器：不再依赖摇杆扩展板，仅通过倾斜手柄（micro:bit 本体），就能让 PU 转弯——手柄向右倾斜 PU 右转，向左倾斜 PU 左转，放平则停。本课引导学生读取倾斜角度（Roll），理解"物理姿态→传感数值→控制指令"的体感交互链路，体验像握方向盘一样操控机器人的乐趣，为综合挑战课储备新的输入方式。

## 课程目标

1. 认识加速度传感器与 Roll（左右倾斜）角度：理解手柄放平接近 0°、右倾为正、左倾为负；

2. 学会读取 Rotation.Roll 并通过无线电发送，掌握"姿态变数据"的传感编程方法；

3. 学会用角度阈值（如 ±20°）过滤手抖，把倾斜角度翻译成 PU 的左转/右转动作；

4. 通过"人体姿态控制机器人"的体验，感受体感交互的直观性，激发创意：还能用什么身体动作控制 PU？

## 课程引入

从第一课到今天，我们控制 PU 用过按键、用过摇杆——手总得"握点什么"。今天来点不一样的：把手柄（micro:bit）平放在手里，它就是一只方向盘。手心向右歪，PU 就向右转；手心向左歪，PU 就向左转；手心放平，PU 就停下。micro:bit 里面藏着一个"水平仪"（加速度传感器），能感知自己被倾斜了多少度。它怎么把"歪了多少"变成机器人的转向指令？让我们把身体变成遥控器！

## 学习探究

1. 旧知巩固：回顾机器人端"读数值→死区判断→执行动作"的三步套路（案例二、三），提问："左右转向用哪两个方向参数？"复习 LeftTurn/RightTurn。

2. 新知识学习——加速度计与 Roll 角度：micro:bit 内置加速度传感器，能测量自身倾斜。其中 Roll（翻滚角）描述"左右倾斜"：放平接近 0°，向右歪是正数、向左歪是负数，单位是度。演示手柄端读取 input.rotation(Rotation.Roll)，倾斜手柄观察读数变化（可先用 LED 显示数值直观感受）。

3. 新知识学习——体感阈值：手拿手柄难免轻微晃动，因此设 ±20° 阈值：只有倾斜超过 20° 才触发转向，防止 PU 抖来抖去。数值通过 SendControlType.Roll 发送，机器人端读取 ControlValueType.Roll 后做判断。

4. 动手验证：烧录后手心向右倾斜超过 20° → PU 右转；向左倾斜 → 左转；放平 → 停住。体会"倾斜角度越大是否转得越快"——本课暂不引入速度联动，角度只决定方向。

## 课堂活动

"人形方向盘"体验赛：学生手持手柄站在场地一端，把 PU 放在另一端。教师发令"向右转！"学生倾斜手柄让 PU 原地右转，看谁能用最少的操作让 PU 转回正对方向；再增加难度：倾斜 + 口令配合，让 PU 完成"右转 90° → 直行"的小任务。小组轮换操作员与观察员，互评操作稳定性。

进阶挑战：再加一个轴——手柄前倾/后仰（Rotation.Pitch，前后倾斜）时让 PU 直走/后退。提示：手柄端把 Pitch 角度通过 SendControlType.Speed 发送，机器人端读取 Speed 值的正负判断前进或后退（参考案例二的方向分支）。

## 总结分享

教师总结：micro:bit 的加速度传感器把"身体姿态"变成"角度数值"，再变成机器人的转向指令——这就是体感控制。它和摇杆控制最大的不同是：输入从"手指拨动"变成了"整只手甚至整个身体的姿态"，交互更直观。至此我们已经掌握了按键、摇杆、文字、体感四种控制方式。下节课是系列收官：把摇杆方向 + 按键动作 + 变量计数组合起来，完成一个"正方形巡游"综合挑战！
