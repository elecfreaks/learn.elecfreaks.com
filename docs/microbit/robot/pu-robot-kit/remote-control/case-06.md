# 案例六：综合挑战——遥控 PU 完成正方形巡游

## 案例简介

本案例是手柄遥控系列第六课（收官课），综合运用前五课所学：摇杆控制方向（案例二、三）、按键发指令（案例一）、动作执行（案例四）与变量计数（本课新知识点）。任务：操作员遥控 PU 沿正方形行走，每走到一个顶点按 B1"报到"，PU 跳跃庆祝并让计数器 +1；当走满 4 个角，PU 自动跳舞庆祝。本课通过一个真实的小任务串联全部知识点，帮助学生建立"拆解任务→组合积木→调试验证"的完整编程思路。

本课由操作员**人工遥控巡游**。B1 用于报角计数，PU 不会自行识别顶点或自动沿正方形导航

## 课程目标

1. 认识变量：理解"变量是装数字的盒子"，能用变量记录"已经走过的角数"并不断累加；

2. 综合运用摇杆方向控制、按键指令、动作执行等已学积木，编写"走正方形 + 数角 + 庆祝"的完整程序；

3. 学会把大任务拆成小步骤（直行—转弯—报角—计数—判断完成），建立任务分解的编程思维；

4. 通过双人协作完成任务，培养团队分工、调试排错与展示交流的综合素养。

## 课程引入

同学们，手柄遥控系列课到今天已经学了很多本领：摇杆能让 PU 前进后退、原地转向，按键能让 PU 直行、跳跃，文字能让它打招呼、跳舞。今天就是"毕业大考"——我们要用这些本领指挥 PU 完成一个正方形巡游：沿地面四个标记走一圈，每到一个角让它跳一下"打卡"，等四个角都走完，PU 会自动跳舞庆祝胜利！怎么让 PU 记住"我已经走了几个角"？这需要请出编程里的新朋友——"变量"。它像一张记数纸，帮 PU 数着数。开工吧！

## 学习探究

1. 旧知巩固：回顾三项已学技能——摇杆四方向判断（案例二/三）、按键 B1 发送数字（案例一）、动作积木（案例四）。请学生上台口述："要让 PU 前进并原地转向 90°，手柄和机器人端各要哪些积木？"

2. 新知识学习——变量：机器人需要"记住"自己走了几个角。变量就像一个带名字的盒子（如 corners），可以放数字。本课套路：程序开始时 corners = 0（空盒子清零）；每按一次 B1（到角报到），执行 corners = corners + 1（盒子里的数加 1，像画"正"字）；当 corners == 4 时说明四个角都走完了，触发跳舞庆祝。

3. 任务拆解：把"正方形巡游"拆成三个子任务——① 摇杆随时控制方向（把案例三机器人端方向代码整段搬来）；② B1 到角报到：收到 1 → 跳跃 + 计数 +1（把案例一按键逻辑扩展）；③ 满 4 角 → 跳舞（新增变量判断）。逐一实现再组合。

4. 动手验证：烧录后操作员推摇杆让 PU 走向 1 号角 → 按 B1，观察 PU 跳跃且"打卡"成功；依次走完 4 个角后，观察 PU 是否自动跳舞庆祝。若按到第 4 角没有跳舞，检查变量是否每角都 +1、判断条件是否写成了 == 4。

## 课堂活动

"正方形巡游挑战赛"：四人一组（操作员、观察员、计时员、记分员），地面用胶带贴出边长约 1 米的四个顶点。小组合作让 PU 依次走完四个角并完成"打卡"，要求每个角都跳一下、最后 PU 自动跳舞，用时最短且动作规范的小组获胜。展示环节请各组分享：编程时把任务拆成了哪几步？调试中遇到过什么问题（如 PU 走偏、计数不对）？是怎么解决的？

进阶挑战：① 把正方形改成三角形——走 3 个角就庆祝（把 corners == 4 改成 corners == 3）；② 让 PU 可以一圈接一圈地跳——数到 3 后把计数器清零（corners = 0）再重新计数；③ 试着让 PU 每到一个角做不同动作（第 1 角跳跃、第 2 角踢球……提示：可以用 if corners == 1 / 2 / 3 分别判断）。

## 总结分享

教师结合挑战赛总结本系列：从第一课的"按一个键做一个动作"，到摇杆实时操控、原地转向、文字对话、体感方向盘，再到今天的变量计数与综合任务——PU 手柄遥控的六大本领全部解锁。回顾整个系列，每一课只学一个新知识，但新知识都建立在前一课之上，这就是"由简到难、循序渐进"的编程学习路径。课后想一想：如果想让 PU 沿正方形巡游时自动避障（结合超声波传感器）或实现多手柄对战，程序还要怎么改？期待大家的创意！
