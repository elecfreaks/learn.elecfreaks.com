# Quick Start


## **Instructions**



- Press the power button for 0\.3 seconds to power on.

- Using the MakeCode platform:

    - Open the platform link and create a new project: https://makecode.microbit.org

    - Click **Extensions**, search for **planetX\-AI**, and click the **planetX\-AI** library to add the extension.

    - Find the **planetX\-AI** tab in the block library on the left, and drag blocks to use them.

    - After programming, Download the program to the micro:bit to run it.

- Using the MicroBlocks platform (coming soon)

    - Open the platform link: https:microblocks.html
      
    - Click **Add Library** in the left panel, then follow the path **"Elecfreaks - PlanetX - AI Lens Pro"**, and click **Confirm** to add it.
      
    - Find the **AI Camera Pro** library tab in the left panel, and drag blocks to use them.
      
    - After programming, connect the Nezha ESP32 Multi-Function Main Control Box, then click the button in the top-right corner of the page or click a block to run the program.
